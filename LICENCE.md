## 🧩 About

**Satisfactory Config** is a comprehensive configuration tool for Satisfactory 1.0 featuring a production planner, recipe browser, save editor, factory overlay, and blueprint manager.

Based on popular tools like **Satisfactory Calculator**, **SCIM**, and **Satisfactory Mod Manager**.

---

## ✨ Features

### 🏭 Factory Planning
- Production Planner — calculate input/output rates for any recipe chain
- Recipe Browser — search all recipes, alternates, and unlock costs
- Throughput Overlay — view machine clock speeds in real time
- Power Grid Monitor — track consumption and generation balance

### 💾 Save & Blueprint Tools
- Save Editor — inspect and edit inventories, unlocks, and milestones
- Blueprint Manager — import, export, and organize factory blueprints
- Map Marker Editor — add and rename resource and POI markers

### 🎛️ Interface & Config
- In-Game Overlay — hotkey-driven panel while playing
- Config Profiles — switch between planning and play presets
- Keybind Editor — remap every tool hotkey
- Session Logger — export build statistics to CSV
